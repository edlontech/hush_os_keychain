# HushOsKeychain

HushOsKeychain is a Hush configuration provider backed by operating system keychains on macOS, Linux, and Windows, allowing applications to use securely stored secrets in their configuration.

## Installation

Add `hush_os_keychain` to your dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:hush_os_keychain, "~> 0.1"}
  ]
end
```
